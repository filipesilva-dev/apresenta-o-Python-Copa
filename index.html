🧵 String = Texto

Uma string é um texto entre aspas. Pode ser nome de jogador, grito de gol, placar, qualquer texto.

jogador = "Vini Jr."
grito    = "GOL"
⚠️ Atenção: 7 (número) é diferente de "7" (texto). A diferença são as aspas: sem aspas é número, com aspas é string.

✅ Tudo que é texto no Python é uma string!

🔗 Concatenação com +

O operador + junta dois ou mais textos em um só. É como colar palavras.

print("GO" + "L")  # GOL
print("Brasil" + " 2 x 1 " + "Argentina")  # Brasil 2 x 1 Argentina

💡 Dica: O + só funciona com textos. Números precisam ser convertidos antes (assunto para outra aula).

É igual juntar as letras do nome do seu time!

🔢 Contagem com len()

A função len() retorna o número de caracteres de uma string. Isso inclui letras, números, espaços e pontuação.

print(len("Neymar"))   # 6
print(len("Cristiano Ronaldo"))  # 17 (espaço conta!)
print(len("Gol!"))       # 4 (inclui exclamação)

⚠️ O espaço é um caractere!

O espaço em branco também é contado por len(). Exemplo: "Ana Maria" tem 9 caracteres, pois o espaço entre os nomes conta como 1.

nome = "Ana Maria"
print(len(nome))  # 9

💡 Dica importante: len() conta todos os caracteres, inclusive espaços e pontuação. Útil para validar tamanho de senhas, nomes, etc.

🔊 Grito .upper() vs Sussurro .lower()

.upper() → tudo MAIÚSCULO

jogador = "ronaldinho"
print(jogador.upper())  # RONALDINHO
print("gol".upper() + "!!!!")  # GOL!!!!

Gritar gol tem que ser em maiúsculo! 🗣️

.lower() → tudo minúsculo

grito = "GOL"
print(grito.lower())  # gol
resposta = "SIM"
print(resposta.lower())  # sim (padroniza)

Quando é gol contra, fala baixinho… 😅

💡 Ambos não alteram a variável original, geram uma nova string.

🤔 Você lembra?

  • ➕ + → junta textos (concatenação)
  • 🔢 len() → conta todos os caracteres (espaços e pontuação inclusos)
  • 🔊 .upper() → transforma em MAIÚSCULAS
  • 🤫 .lower() → transforma em minúsculas
