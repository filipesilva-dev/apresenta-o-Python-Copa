🧵 String = Texto

Uma string é um texto entre aspas nome de jogador, grito de gol, o que for!

jogador = "Vini Jr."
grito    = "GOL"
⚠️ Atenção: 7 (número) é diferente de "7" (texto)!
A diferença são as aspas: sem aspas é número, com aspas é string.

✅ Tudo que é texto no Python é uma string!

🔗 Concatenação com +

O + cola dois textos, formando um só sem espaço extra, a menos que você peça.

print("GO" + "L")  # GOL
print("Brasil" + " 2 x 1 " + "Argentina")  # Brasil 2 x 1 Argentina

É igual juntar as letras do nome do seu time! ⚽

💡 O + só funciona com textos. Números precisam ser convertidos.

🔢 Contando com len()

len() conta tudo dentro da string: letras, números e espaços.

print(len("Neymar"))   # 6
print(len("Cristiano Ronaldo"))  # 17 (espaço conta!)

Vamos contar as letras dos craques! 🇧🇷🇦🇷

⚠️ O espaço é um caractere!

len() conta espaços também eles contam como um caractere igual a qualquer letra.

nome = "Ana Maria"
print(len(nome))  # 9 → o espaço conta como 1
💡 Importante: Isso afeta validação de formulários, senhas e comparações de texto.

🔊 Grito de gol – .upper()

.upper() transforma todos os caracteres em MAIÚSCULAS ideal para gritar!

jogador = "ronaldinho"
print(jogador.upper())  # RONALDINHO

grito = "gol"
print(grito.upper() + "!!!!")  # GOL!!!!

Gritar gol tem que ser em maiúsculo! 🗣️⚽

💡 .upper() não altera a variável original gera uma nova string.

🤫 Sussurro – .lower()

.lower() transforma todos os caracteres em minúsculas.

grito = "GOL"
print(grito.lower())  # gol

resposta = "SIM"
print(resposta.lower())  # sim (padroniza)

Quando é gol contra, a gente fala baixinho… 😅

💡 .lower() também não modifica a original retorna uma nova string.

🤔 Você lembra?

  • ➕ + → junta textos
  • 🔢 len() → conta caracteres (espaços também!)
  • 🔊 .upper() → MAIÚSCULAS
  • 🤫 .lower() → minúsculas
