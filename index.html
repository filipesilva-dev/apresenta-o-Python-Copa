🧵 String = Texto

📌 O que é? É uma "Linha" de caracteres que você escreve entre aspas!

Uma string é um texto entre aspas. Pode ser nome de jogador, grito de gol, placar, qualquer texto.

jogador = "Vini Jr."
grito    = "GOL"
👀 Olho no lance: 7 (número) é diferente de "7" (texto). A diferença são as aspas! Números não têm aspas, textos têm!
📺VAR: Aspas são o que diferenciam número de texto.Segue o jogo!

🔗 Concatenação com +

⚡ Juntar textos é como colar figurinhas da Copa!

O operador + junta dois ou mais textos em um só.

print("GOL" + "!!!!!")  # GOL!!!!!
print("Brasil" + " 2 x 1 " + "Argentina")  # Brasil 2 x 1 Argentina
👀Olho no lance: O + não coloca espaço automático, adicione você mesmo!
📺VAR: Sem espaço, vira "Brasil2x1Argentina".Segue o jogo!

🔢 Contagem com len()

📏 Quantas letras tem o nome do craque?

len() conta todos os caracteres: letras, números, espaços e pontuação.

print(len("Neymar"))   # 6
print(len("Cristiano Ronaldo"))  # 17 (espaço conta!)
👀 Olho no lance: Espaço também é caractere para o len()!
⚠️ O espaço é um caractere! "Ana Maria" tem 9 caracteres (o espaço entre os nomes conta!). 
nome = "Ana Maria"
print(len(nome))  # 9
📺 VAR: Você lembrou que espaço conta? Segue o jogo!

🔊 Grito .upper() vs Sussurro .lower()

🏆 Gritar gol é .upper()! Gol contra é .lower()… 😅

.upper() → tudo MAIÚSCULO

jogador = "ronaldinho"
print(jogador.upper())  # RONALDINHO
print("gol".upper() + "!!!!")  # GOL!!!!
👀Olho no lance: Grite com .upper()!

.lower() → tudo minúsculo

grito = "GOL"

print(grito.lower())  # gol
👀Olho no lance: Gol contra? Fala baixo com .lower()! 😅
📺VAR: .upper() e .lower() não modificam a original, geram uma nova string.Segue o jogo!
